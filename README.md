# Beatriz Moraes — Portfólio

Portfólio profissional em Controladoria, análise de dados e gestão.

Site: https://beatrizmoraesr24-hub.github.io/

## Desenvolvimento

Node.js 22.12+ ou 24. Instale com `npm ci`, execute `npm run dev` e gere a publicação com `npm run build`.

O build produz a pasta `docs/`, publicada pelo GitHub Pages a partir da branch `main`. Após alterações, gere novamente o build e envie também a pasta `docs/`.

## Conteúdo

- Dados profissionais e certificações: `src/portfolioData.ts`.
- Estrutura, contato e avatar interativo: `src/App.tsx`.
- Aparência e responsividade: `src/styles.css`.
- Currículo: `public/curriculo-beatriz-moraes.pdf`.
- Avatar: `src/assets/beatriz-avatar.png`, ilustração gerada a partir da foto de referência, com profundidade e iluminação em CSS.

Layout adaptado do projeto Tognolli0/Site, conforme autorização do autor. Informações profissionais baseadas no currículo fornecido e no perfil público de Beatriz Moraes. As áreas de atuação descrevem experiências, não repositórios ou projetos públicos.
